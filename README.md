## Installing a mod

- **The easy way:** in the Jester Launcher, open Mods and add it. The launcher checks every file first.
- **By hand:** download the zip from the mod's `versions` folder and unzip it into a folder under the game's `Mods` folder.

## Sharing a mod

Upload it on [jestercastles.com/mods.html](https://jestercastles.com/mods.html) (you need to own the game and confirm your email). Pull requests to this repository are not accepted: everything here goes through the site's checks and a moderator.

## Layout

```
mods/<author>/<mod>-<id>/README.md        the mod's page
mods/<author>/<mod>-<id>/mod.json         its facts and every version
mods/<author>/<mod>-<id>/screenshots/     up to 4 pictures
mods/<author>/<mod>-<id>/versions/<v>/    each approved version's zip
index.json                                the whole list, for tools
```
